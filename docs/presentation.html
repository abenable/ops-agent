Marconi Infrastructure Operations Agent

A Discord bot that answers questions about the lab's Docker services by actually looking: container state, logs, and metrics, read live and cited in the answer.

PREPARED BY ABLE INTERNSHIP PROJECT 2026
THE PROBLEM

Something breaks. Someone has to go look.

The lab's services run across Docker, Prometheus, and Loki, three separate places to check before anyone knows what happened.

BEFORE
  • Notice something looks wrong, or wait for someone to ask
  • docker ps, docker logs, Grafana, Loki: four tools, by hand
  • Piece the story together from three tabs, with no record of how you got there
AFTER
  • Ask in plain English, in Discord, from a phone if needed
  • The agent runs the same checks, with tools, not memory
  • One answer with the evidence attached, and it watches on its own too
WHAT IT DOES

Ask a question. Get an answer, with receipts.

you> why did the api container restart? oracle> tool call: list_services() tool call: docker_status(container="marconi-agent-api") tool call: query_loki_range(logql='{container="marconi-agent-api"}', minutes=30) What happened — marconi-agent-api restarted 12 minutes ago… Likely cause — OOM: the log shows MemoryError immediately before exit. Next steps — raise the container memory limit, or cap the batch size.
  • Conversational: DM it or @mention it, follow-ups included; it remembers the thread per channel
  • Slash commands for the structured cases: /investigate, /status, /report, /digest, /watch
  • Same core over HTTP: an optional API serves the same workflows to anything that isn't Discord
BEYOND Q&A

It also watches, without being asked.

A background loop polls containers and endpoints, evaluates PromQL rules, and reports on a schedule, independent of anyone asking a question.

every 2hstatus snapshot posted#status-updates
on changewatched container stops, or a PromQL rule fires#incidents
dailydigest of what happened today#reports
weeklydigest summarizing the week#reports
ARCHITECTURE

One agent. Every workflow shares it.

SAFETY

It can look. It cannot touch.

Every tool the model can call is a read. Nothing restarts, scales, or deletes anything, on purpose.

  • All 10 tools query Docker, Prometheus, and Loki: none of them mutate
  • The system prompt tells the model to recommend actions for a human operator, not to claim it can take them
  • The guarantee is the tool surface itself, not a permission flag layered on top
